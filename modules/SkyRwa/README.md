# SkyRwa: Modeling Governable Flight-to-Asset Lifecycles with Knowledge Graphs, SHACL, and Provenance

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

**This module is the software artifact for the paper** *"Modeling Governable Flight-to-Asset Lifecycles with Knowledge Graphs, SHACL, and Provenance"*, submitted to the **Journal of Web Semantics**. Everything reported in the paper — ontology, SHACL shapes, SPARQL queries, benchmark, and all evaluation tables and figures — is generated by the code in this directory.

---

## One-Command Reproduction

```bash
git clone https://github.com/liuyushugreat/SkyNetUamPlatform.git
cd SkyNetUamPlatform/modules/SkyRwa/reproduction

pip install -r requirements.txt

bash run.sh          # Linux/macOS
# .\run.ps1          # Windows PowerShell
```

**Expected total runtime: ~10 minutes** on a laptop-class CPU (13 steps; step 5, the scoring-context cost study, accounts for ~6 minutes). All results are written to `reproduction/outputs/` (JSON + the generated walkthrough LaTeX) and `reproduction/data/` (benchmark data).

### Clean-room run (Docker)

```bash
cd SkyNetUamPlatform/modules/SkyRwa
docker build -t skyrwa-artifact .
docker run --rm skyrwa-artifact        # runs tests + full pipeline
```

## Overview

**SkyRwa** formalizes the governance transitions that turn raw UAM flight data into tradable data assets as first-class semantic objects in a knowledge graph. The core model is a **four-tier governance lifecycle**:

```
FlightEvidence ── governance ──► AssetCandidate ── aggregation ──► GovernedDataProduct ── settlement ──► RevenueRight
   (Tier 1)                        (Tier 2)                          (Tier 3)                             (Tier 4)
```

- **Tier 1: Flight Evidence** — raw attestation with SHA-256 digest + Ed25519 signature. Not tradable.
- **Tier 2: Asset Candidate** — governed evidence with scores, valuation, and rights profile.
- **Tier 3: Governed Data Product** — aggregated from multiple candidates; catalogued and licensable.
- **Tier 4: Revenue Right** — usage events, settlement records, and revenue splits.

Transitions are not function calls but **typed entities** (`skyrwa:GovernanceDecision`, a `prov:Activity` with rule ID, explanation, timestamp, and `prov:used`/`prov:generated` edges), so the *why* behind every promotion or blocking is queryable.

> **Synthetic benchmark note:** current civil-aviation regulations (CAAC) prohibit releasing operational UAM data. The benchmark is synthesized from published regulatory envelopes; the generator (fixed seed 42), parameter distributions, and a violation coverage matrix ship in `benchmarks/` and `benchmark_generator/`.

## Semantic Web Artifacts

**Ontology.** 14 OWL classes, 47 properties (19 object, 28 datatype), namespace `https://w3id.org/skyrwa#`, version 1.0.0. Alignments are asserted axioms (not annotations): `FlightEvidence ⊑ prov:Entity`, `GovernanceDecision ⊑ prov:Activity`, `GovernedDataProduct ⊑ dcat:Dataset`, `RightsProfile ⊑ odrl:Policy`, `UAV ⊑ sosa:Platform`, plus property-level subsumptions. Serializations: Turtle, RDF/XML, JSON-LD; pyLODE docs under `docs/ontology/`.

**SHACL.** Six node shapes in five files (evidence, candidate, product, usage, settlement, revenue share), including one `sh:sparql` conditional constraint; an optional extended contract (`shapes/extended/`) checks the V3/V4/V6 threshold rules declaratively when scoring context is materialized (`--materialize-scoring-context`).

**SPARQL.** Twelve competency questions (core CQ1–6; negative CQ7–8; temporal CQ9–10; cross-tier aggregation CQ11–12) plus five analytical queries. All twelve CQs verify against pipeline ground truth (Table 11).

**Validation engines.** `semantic_rules/validation_runner.py` wraps both **pySHACL** (full coverage incl. `sh:sparql`) and **rudof** (SHACL Core, ~16× faster end-to-end at 1 000 flights).
