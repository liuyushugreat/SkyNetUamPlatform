Description

Domain ontology for transforming UAM flight records

into governable, valuatable, and tradable data assets. The ontology

distinguishes raw flight evidence from governed asset candidates,

aggregated data products, and revenue-right objects.

Flight Evidence c

IRI https://w3id.org/skyrwa#FlightEvidence
Description

  • A signed, digest-carrying attestation over a bundle of sensor observations (cf. sosa:ObservationCollection); governance applies to the attestation, not to individual observations.

  • Raw, unprocessed attestation of a single UAM flight.

    Contains telemetry summaries, environment context, mission results,

    and cryptographic digests. NOT directly tradable.
Sub Class Of Entity c
In Domain Of

  • operated by op
  • performed by UAV op
In Range Of derived from evidence op

has rights profile op

IRI https://w3id.org/skyrwa#hasRightsProfile
Description

  • Attaches the governance-assigned odrl:Policy to the asset.

    Each permitted_use maps to an odrl:Permission, each prohibited_use to an

    odrl:Prohibition; tradability corresponds to an odrl:Permission with

    odrl:action odrl:distribute, and desensitization to an odrl:Duty.

  • Links an asset candidate to its governance-assigned rights (equivalent to attaching an odrl:Policy).
Sub Property Of odrl:hasPolicy
