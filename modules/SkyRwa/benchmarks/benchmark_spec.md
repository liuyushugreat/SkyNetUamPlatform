# SkyRwa Benchmark Specification

## Objective

Provide a reproducible, diverse benchmark dataset for evaluating the
SkyRwa flight-to-asset pipeline, SHACL validation coverage, SPARQL
queryability, and semantic layer overhead.

## Data Distribution

| Scenario | Count | Expected Tradable | Has Violations |
|---|---|---|---|
| Clean route survey | 5 | Yes | No |
| Night flight | 4 | Yes | No |
| Weather disturbance | 4 | Yes | No |
| Near-NFZ event | 3 | Mixed | Mixed |
| Anomaly-rich maintenance | 4 | Yes | No |
| Emergency logistics | 3 | Mixed | Mixed |
| Incomplete / low-quality | 4 | No | Yes |
| Rights-conflicted aggregation | 3 | Yes | No |
| **Total** | **30** | ~22 | ~7 |

## Label Definitions

Each benchmark flight receives the following expected labels:

- `expected_tradable` — whether governance should mark the asset tradable
- `expected_quality_above_05` — whether data quality score exceeds 0.5
- `expected_compliance_above_07` — whether compliance score exceeds 0.7
- `has_violations` — whether the input contains regulatory violations
- `completed` — whether the flight mission completed successfully

## Invalid / Edge Cases

1. **Missing digest** — injected by omitting digest computation
2. **Negative share percentage** — tested in unit tests
3. **Tradable without rights profile** — tested via SPARQL CQ5
4. **Product from insufficient sources** — tested via ProductBuilder
5. **NFZ incursion** — scenario 4 introduces 1–2 incursions
6. **Sensor failure + telemetry loss** — scenario 7

## Output Artifacts

Generated by `generate_benchmark.py`:

| File | Format | Description |
|---|---|---|
| `sample_data/benchmark_flights.json` | JSON | Raw input scenarios |
| `sample_data/benchmark_assets.json` | JSON | Processed asset units |
| `sample_data/benchmark_labels.json` | JSON | Expected labels per flight |
| `sample_data/benchmark_summary.json` | JSON | Aggregate statistics |
| `sample_graphs/benchmark_graph.ttl` | Turtle | Full RDF graph |
| `sample_graphs/benchmark_graph.jsonld` | JSON-LD | Full RDF graph |

## Reproduction

```bash
cd SkyNetUamPlatform/modules
python -m SkyRwa.benchmarks.generate_benchmark
```
