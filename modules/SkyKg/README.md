# SkyKG Module Bundle

This directory groups the modules related to the `research/papers/Knowledge_Engine`
paper and its implementation in the repository.

## Included Modules

- `SkyNet_Knowledge_Engine/`: ontology, neuro-symbolic reasoning, and LLM-based explanation
- `voxel_airspace_core/`: voxelized 3D airspace indexing and adaptive octree support

## Excluded Modules

- `SkyFlow/`: conflict detection research for a different paper
- `SkyRwa/`: pricing and economics utilities, not part of the SkyKG paper workflow
