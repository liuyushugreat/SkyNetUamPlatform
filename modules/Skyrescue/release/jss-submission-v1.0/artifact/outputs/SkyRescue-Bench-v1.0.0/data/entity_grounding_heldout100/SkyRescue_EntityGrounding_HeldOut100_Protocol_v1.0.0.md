在地点实体锚定器、本体词表和阈值已冻结的前提下，使用 100 条新的人工低空应急指令检验 DeepSeek、千问与 SkyRescue 完整编译流程。该数据集不得用于调整本体、阈值、提示词或规则。

## 3. 指令采集

1. W01 专家填写 `HLD-001`—`HLD-050`。
2. W02 专家填写 `HLD-051`—`HLD-100`。
3. 专家只阅读分配行的 `scenario_card`，用自己的低空交通或应急指挥口吻从零写 `instruction_text`。
4. 不得查看旧 100 条数据、模型回答、本体词表或标准标签，不得使用 AI 代写。
5. 可键盘输入或语音转写；语音转写后由专家本人核对。
6. 禁止记录真实个人信息、精确住址、未公开事故或受控航线信息。
7. `Progress` 页必须显示 `Complete=100`、`Incomplete=0`。

## 4. 双人独立标注

指令采集完成后，再生成不含 AI 预标注的 `Annotator_A` 和 `Annotator_B` 工作簿。两名标注者在不查看对方结果的情况下独立标注所有字段。全部提交后计算各字段 Cohen's kappa，再由第三位专家裁决分歧。

## 5. 模型盲测

1. 标准标签密封，模型输入仅包含 `confirm_id` 和 `instruction_text`；`scenario_card`、场景类别、作者元数据、本体词表和任何标准标签均不得发送给模型。
2. DeepSeek 和千问使用确证性实验开始前冻结的模型版本、instruction-only 系统提示词、`temperature=0`、`top_p=1` 和单次响应。
3. 先保存全部 200 份原始模型响应、请求参数、模型返回版本、时间戳和用量记录。
4. 原始响应完整保存之后，才允许打开裁决后标准标签。

- 直接 JSON 解析率

- 严格地点文本准确率

- 精确编译结果准确率
- 按场景类别的分层结果和 95% 置信区间

正式报告必须保留所有失败类型和负面结果。如确证集表现下降，不得修改冻结本体后用同一批数据重新宣称为盲测。
